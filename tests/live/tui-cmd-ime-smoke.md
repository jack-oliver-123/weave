# Windows 11 CMD 中文输入法 smoke

此门槛必须在真实 Windows 11 `cmd.exe` 与日常使用的中文输入法中人工执行。pane 文本和自动化截图不能证明候选窗位置。经典 Console Host 无法区分 `Shift+Enter` 与 `Enter`，使用 `Ctrl+J` 换行；Windows Terminal 1.25+ 在增强键盘协议协商成功时使用 `Shift+Enter`。

## 启动

1. 在项目根目录执行 `npm run build:e2e`。
2. 打开经典 CMD 或 Windows Terminal 的 CMD profile，执行 `node .e2e-dist/tests/fixtures/tui-app.js`。
3. 确认只出现一个 Weave 头部、一个输入框和一个状态栏。

## 记录

- Windows 版本：Windows 11 专业版，版本 `10.0.26200`，内部版本 `26200`
- 终端宿主与版本：经典 Console Host（`conhost.exe`）；Windows Terminal 稳定版 `1.24.11911.0`；Windows Terminal Preview `1.25.1912.0`
- 输入法与版本：微软中文输入法组件 `ChsIME.exe`，文件版本 `10.0.26100.8328 (WinBuild.160101.0800)`
- 缩放比例和字体：系统 DPI `96`（`100%`）；经典 Console 根配置 `FaceName=__DefaultTTFont__`、字号高度 `16`
- 失败项及复现步骤：无遗留失败项；Windows Terminal Preview 首次启动命令因标题参数引用错误返回 `0x80070002`，修正参数边界后成功启动夹具，不影响功能验收结果。
