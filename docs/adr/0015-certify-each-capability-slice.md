# 每个能力切片必须独立认证

Capability Slice 只有同时通过授权契约、标准化属性与模糊测试、数据泄露、真实 OS 负向探测、Runner 控制面攻击、事务与审计故障注入、资源和进程限制，以及真实 HITL E2E，才能在对应 backend 上启用。普通 CI 负责全部确定性测试；需要特权或真实 OS 的探测生成独立认证证据，并在运行时由 Sandbox Capability Report 再次验证。

“未运行”“平台不支持”“结果未知”、测试跳过或不稳定都不算通过，对应能力保持关闭。构建期认证不能替代运行时身份确认和主动负向探测，单元测试、版本检测或依赖存在也不能单独证明 OS 隔离成立。
