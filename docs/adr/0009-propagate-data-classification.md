# 派生内容保守继承数据分类

Weave 的每个内容片段携带包含来源、分类、用途和内容摘要的 Provenance Envelope。宿主执行的拼接、截取和编码等透明变换取全部输入的最高分类；模型、Shell、进程和未知扩展属于不透明变换，其输出默认继承它能够读取的所有输入中的最高分类。检测器与项目规则只能提高分类，不能把继承的敏感或凭据分类降低为普通数据。

可信 Adapter 可以把不包含原始内容的退出码、计数和布尔状态等字段独立分类，但无法证明隔离时必须按最高分类处理。授权某次 DataDisclose 只允许精确内容前往指定出口，不改变内容本身的分类或自动授权派生内容。Credential Data 不得进入模型或普通进程；在输出中发现时立即阻断。该设计会增加敏感任务的确认次数，但避免把模型改写、Shell 转码或摘要生成误当成安全降密边界。
