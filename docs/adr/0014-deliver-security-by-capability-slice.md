# 权限系统按能力切片渐进交付

Weave 不会在安全内核完成后一次性开放全部工具，而是按能力切片启用：先完成只支持纯文本模式的 Action Gateway、Secure Context Ledger、策略、HITL、数据守卫、审计与配置基础；随后依次认证只读文件、事务写入、进程执行，以及受控网络、凭据和 Memory 持久化。每个切片必须同时具备应用裁决、OS 强制、结果披露、审计、验收测试与主动负向探测，才能从 Capability Shaping 中变为可见。

Linux/WSL2 与 Windows backend 独立认证和启用；某个平台或能力尚未完成时，只提供纯文本模式或已认证的更小能力集。每个阶段都可以发布，但只能声明已认证能力可用，不能把局部实现称为完整权限系统。产品不提供 `--unsafe`、宿主工具回退或临时绕过 Sandbox 的开关。
